# Баланс

## Утверждено и не меняется настройками этого этапа
Самостоятельная техника75% после отсутствия клановой; один владелец SixEyes/сезон;
порог перегрузки80, выход70%, снятие40 и3сек; регенерация одинакова в бою и вне боя.

## Предложено и реализовано
Новый профиль:100CE,100выхода/с,контроль20,потери30%,регенерация1/с.
Выход100 — совместимость с текущими тестовыми приёмами20/30/60, не финальная RPG.
Старые значения не заменяются этими дефолтами. Клановые вероятности остаются прототипными.
Восемь самостоятельных ID равновероятны; категории редкости не умножают урон.
Нормальный потенциал всех пяти направлений — нейтральный миграционный вариант.

`<мир>/serverconfig/jujutsurpg-foundation-server.toml`:
- sixEyesLossMultiplier=0.1 — снижает лишь долю потерь; при30% получаем3%, стоимость20→20.6.
- reinforcementCostPerSecond=3 — с30%потерь3.9CE/с против регенерации1CE/с.

Остальные числа пока константы: охлаждение5напряжения/с, накопление output/2;
атака+2,броня+4,баланс+1/+2. Их вынос в настройки — следующий этап после стабилизации тестов.
Обратная миграция Efficiency сохраняет прежний расход, поэтому старый профиль с Efficiency1
будет иметь0%потерь; не подменять его новым30% без согласованной процедуры.
