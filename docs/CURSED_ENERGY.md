# Проклятая энергия

**Утверждено:** пять независимых параметров; расход=base×(1+loss); постоянная онлайн-регенерация
в бою/вне боя; без офлайн-регенерации; при0CE физический бой без штрафа;
перегрузка при80, выход70%, снятие при≤40 и минимум60тиках.

**Реализовано:** серверное хранилище v2, общая транзакция, конечные неотрицательные аргументы,
общее скользящее окно20тиков для требуемого выхода, тик только живого онлайн-игрока.
CE не может уйти ниже0. Максимальная ёмкость0 поддерживается математически, но полноценное
Небесное ограничение пока не назначается. Перегрузка сохраняется вместе с остатком онлайн-тиков.
Смерть/офлайн не восстанавливают CE. Нет автоматического ускорения вне боя.

Старая Efficiency переводится в Loss=(1/efficiency)-1, сохраняя прежнюю стоимость.
Старое числовое значение CE мигрирует без заполнения до максимума.
Новые поля добавляются отдельно; устаревшее Efficiency оставлено для диагностики.
У новых профилей100CE,100выхода,20контроля,30%потерь,1CE/с.
Выход100 сохранён вместо предложенных20, чтобы существующие мгновенные красный/фиолетовый
с требованиями30/60 не стали недоступны до реализации прогрессии. Это временный баланс.

Накопление напряжения остаётся прототипным: requiredOutput/2 за расход; охлаждение5/с.
Пороговые правила утверждены, эти скорости — нет. Ни расход, ни регенерация не зависят от FPS.
В полном спокойном состоянии тик не помечает сохранение грязным. HUD обновляется раз в20тиков;
мгновенное действие дополнительно обновляет CE; поддерживаемое — без отдельного пакета каждый тик.

Поддерживаемое усиление: баланс/атака/защита, повторное нажатие выключает.
По умолчанию3базовых CE/с плюс потери и3выхода/с. При нехватке ресурса/выхода выключается
до нового намерения игрока, не дёргается автоматически после регенерации.
Используются только собственные transient-модификаторы, чужие эффекты зелий не снимаются.
DEV infinite требует OP и не обходит требования выхода/перегрузки.

Известная граница: короткое окно расхода до1сек не сохраняется после перезапуска сервера.
Сам запас, напряжение и минимальное время перегрузки сохраняются.
