# Наследственные техники после выбора

Семейный пул задаётся в ClanDefinition.Inheritance, а не центральным switch по клану.
Новый клан добавляется регистрацией определения, школ, упражнения и наследственного пула.
После неудачного семейного броска действует75%-й самостоятельный пул восьми канонических ID.
Инумаки дополнен ID cursed_speech; боевые приказы ещё не реализованы.
Исторические линии не получают приписанную автором «официальную семейную технику».

Техника одна, создаётся до пробуждения и хранится секретно. Каталог возможных семейных техник
публичен, результат конкретного игрока до пробуждения в сеть не передаётся.
Клановый XP, репутация, школа, экзамен и сезон не заменяют технику и не дают Шесть глаз.

**Работает ранее:** синий, красный и фиолетовый для пробуждённой Безграничности, общие усиления.
**Пока отсутствует:** survival-пробуждение, отдельное владение техникой, полноценные условия
освоения высоких приёмов. OP test-awaken и DEV сохранены для отладки. Существующий доступ
к прототипным атакам не выдаётся за клановый уровень; окончательные требования Красного/
Фиолетового по знаниям и генетике ещё нужно добавить с отдельной прогрессией техники.

Десять теней: будущие ритуалы подчинения, а не автоматическая выдача Махораги за уровень.
Проекция:24логических кадра отдельно от20TPS; пока ID без движка маршрутов.
Кровь: нужен отдельный ресурс крови, без бесконечного производства из CE.
Речь: будущие фиксированные команды, слышимость, отдача, сопротивление и защита от цепочек контроля.
Ни одна из этих ещё не реализованных систем не выдаётся за готовую механику.
