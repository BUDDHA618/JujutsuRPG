# Каталог: реализация и предложения

Канонические названия из пользовательского задания. Все численные правила ниже — игровые
предложения, не утверждения о точной механике манги. Боевые приёмы новых восьми ID отсутствуют.

| Техника | Предложенный первый приём / развитие | Требования и ограничения | PvP-контрмера | Приоритет |
|---|---|---|---|---|
| Пропорция | пометка7:3 / усиленный точный удар | пробуждение, контроль20, mastery0; тест8CE,8выхода; бонус лишь подтверждённому ближнему попаданию | разрыв дистанции, блок, уклонение |1 |
| Управление инструментом | управление одним инструментом / несколько траекторий | контроль25, mastery0; тест2CE/с; один предмет с UUID, без дублирования | укрытие, потеря видимости |2 |
| Чёрные птицы | один разведчик / направленная атака | контроль25; тест10CE+1/с; лимит1, команды через сервер | устранение птицы, укрытие |после призывов |
| Буги-вуги | обмен двумя совместимыми целями / комбинации | контроль30; тест12CE; дальность12, безопасная позиция, запрет пересечения измерений | разрыв дальности, отказ цели при защите региона |3 |
| Благоприятные звери | одна форма / последовательное освоение | контроль30; тест15CE; разные этапы ритуала, один режим | прерывание подготовки, давление |после призывов |
| Инверсия | ограниченное защитное окно / точная настройка | контроль35; тест4CE/с; верхний/нижний порог, без лечения отрицательным уроном | слабые серии, атаки вне окна |позже |
| Любовное рандеву | метки / маршрутизация приближения | контроль40; тест5CE/метку; ограничение числа/времени, серверная геометрия | снятие меток, соблюдение порядка |позже |
| Манипуляция небом | краткое отклонение снаряда / пространственный удар | контроль40; тест18CE; конус и время, без абсолютной защиты | ближний бой, фланг |позже |

Общее пробуждение раскрывает уже сохранённый ID, не новый бросок. Предлагаемые упражнения
освоения соответствуют результату приёма: точный удар, проводка предмета через точки,
разведка цели, безопасный обмен, управление призывом, защита окна, маршрут меток, отклонение снаряда.
Продвинутые применения требуют mastery40/60/80 и отдельного испытания; числа ещё обсуждаются.

**Существующая Безграничность:** синий/красный/фиолетовый имеют серверные эффекты;
нейтральная Бесконечность, территория, мастерство и проверка высоких применений Шестью глазами
ещё не реализованы. Десять теней, Проекция и Кровь пока генетические ID без полноценного набора.
