# Сезоны

**Реализовано:** один серверный SeasonLedger, монотонный номер, участники по UUID, единственный
владелец и архив прежних участников/владельцев. Смерть, неактивность и повторный вход слот не освобождают.

```text
/jjkseason status
/jjkseason enroll ИмяИгрока
/jjkseason draw
/jjkseason next ТекущийНомер
```
Все команды требуютOP. Выбор Годжо даёт только совместимость; регистрация и draw ручные.
Сугаваре или другому происхождению Шесть глаз автоматически не доступны. Полное физическое
ограничение несовместимо с текущим отбором. Повторный draw занятого слота отвергается.

Персональные UUID, CharacterId, CreatedSeason и активный номер сезона различаются.
Текущая политика перехода: происхождение, техника, CE, клановый прогресс, вещи и постройки
СОХРАНЯЮТСЯ; меняются активные права Шести глаз, старые остаются в архиве.
Это безопасная политика данного этапа, а не готовая настраиваемая система сброса персонажей.
Создание нового сезонного персонажа и конфигурация переноса вещей/прогресса пока не реализованы.
Новый сезон не открывает обычному игроку новый бросок генетики.

Шесть глаз снижают долю потерь множителем из serverconfig (по умолчанию0.1), не отменяют
базовую стоимость. Ни клановый уровень100, ни репутация не могут выдать признак.
DEV/миграция владельца в другой клан не освобождают занятый слот.
