# Прогрессия — следующий этап, НЕ реализована

**Утверждено:** пять независимых навыков,25–45активных часов до90, отсутствие пассивного XP.
Владение техникой отдельно от CE. Экзамен не перебрасывает генетику.

**Предложение:** сохранять SkillProgress(level,xp,passedMilestones) отдельно для каждого навыка.
XP-ориентир100+6L+0.25L²; до90 требуется92771.25XP, при35часах — около0.736XP за активную секунду.
Перед принятием формулы пересчитать сумму тестом; награда идёт за завершённое упражнение,
не за каждую секунду. Экзамены40/60/80/90/100 открывают следующий этап.

Пять будущих упражнений:
| Навык | Серверно проверяемый результат |
|---|---|
| Запас | удержать поток, меняя опорные точки по выданному маршруту |
| Выход | серия импульсов заданной мощности по отмеченным мишеням |
| Контроль | последовательно выбрать случайные цели в широком временном окне |
| Эффективность | выполнить задачу в бюджете потерь, без простого прожигания CE |
| Регенерация | цикл расхода/стабилизации с активным перемещением между этапами |

Сессия содержит UUID, одноразовый nonce, срок, этап, сложность, серверные наблюдения.
Клиент передаёт намерение, а не XP/успех. Повторный nonce отклоняется. Logout/death отменяют
незавершённую сессию. Упрощённые задания дают меньшую награду; дневных лимитов нет.
Рандомизация и проверка игровых действий снижают AFK, но не обещают невозможность любых ботов.

Пробуждение после30–60мин активных начальных занятий — гарантированное испытание концентрации.
Сейчас есть только OP-команда test-awaken; полноценного пользовательского испытания ещё нет.
Ранги, физические навыки, отдельное владение, награды заданий — план.
