# Происхождения JujutsuRPG — итерация2.0

Статус: восемь основных путей из задания зарегистрированы и доступны в игре.
Это основной игровой каталог, а не заявление об исчерпывающем перечислении всех фамилий манги.

| ID | Происхождение / группа | Учебная специализация | Наследственная техника |
|---|---|---|---|
| gojo | Годжо / великий клан | точность, барьерная школа, пространственная ветка | Безграничность, шанс20% |
| zenin | Зенин / великий клан | оружие, скорость, наследственная ветка | Десять теней10%, Проекция20% |
| kamo | Камо / великий клан | ресурсы, дистанция, кровь | Манипуляция кровью40% |
| inumaki | Инумаки / известная семья | дисциплина воздействия, поддержка, речь | Проклятая речь30% |
| fujiwara | Фудзивара / историческая линия | разведка, взаимодействие, позиция | семейная техника не назначается |
| abe | Абэ / историческая линия | защита, печати, поддержка | семейная техника не назначается |
| sugawara | линия Сугавары / историческая линия | исследование, общие техники, барьеры | семейная техника не назначается |

Все проценты семейного наследования — **предложенный тестовый баланс**, не канон.
Утверждено75% самостоятельной техники, только если семейная не досталась.
Клан не даёт множителя урона, запаса или регенерации CE. Шесть глаз не выдаются за уровень.

## Канон и источники
- [Официальные персонажи первого сезона](https://jujutsukaisen.jp/character/index_1st.php):
  Зенин и Камо названы представителями великих семей; Инумаки связан с линией проклятой речи.
- [Официальные персонажи арки прошлого](https://jujutsukaisen.jp/character/category6.php):
  Годжо — линия одного из трёх великих кланов и пользователь Безграничности.
- [Официальные персонажи Culling Game](https://jujutsukaisen.jp/character/?category=jujutsu):
  Уро связана с подразделением Фудзивара; из этого НЕ следует, что её техника наследуется всеми Фудзивара.
- [Jujutsu Kaisen0: официальный сайт](https://jujutsukaisen-movie.jp/): указатель к первоисточнику
  истории Оккоцу. Сведения о Сугаваре приняты из задания; точную генеалогическую формулировку
  следует сверять с финалом тома0, она не выдумывается по краткой странице фильма.
- [Официальное издание главы238](https://www.viz.com/shonenjump/jujutsu-kaisen-chapter-238/chapter/40387):
  указатель для исторических семей. Полный текст за подпиской здесь не проверен;
  подробности Абэ не объявляются независимо подтверждёнными веб-проверкой.

**Авторская адаптация:** современные учебные школы Фудзивара, Абэ, Сугавары,
все игровые задания, специализации, уровни и репутация. Никакой общей «канонической техники Абэ»
или гарантированной Манипуляции небом Фудзивара нет. Инумаки без Речи учится общим дисциплинам.
Школы с названиями барьеров/поддержки сейчас обучают базовым упражнениям; настоящий барьерный
или командный боевой эффект ещё не реализован.

## Дополнительные пути — предложения, не добавлены в выбор
Оккоцу: ветвь происхождения, без гарантии Копирования/Рики.
Фусигуро: связь с Зенин, не четвёртый великий клан и не гарантия Десяти теней.
Итадори: персональная сюжетная линия не означает выдачу сил Сукуны всем игрокам.
Кугисаки: возможный путь семейного обучения после проверки первоисточника и реализации техники.
Ни один из этих путей пока не выдаётся сервером.
