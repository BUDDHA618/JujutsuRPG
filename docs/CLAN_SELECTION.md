# Выбор происхождения

**Новое утверждённое правило2.0:** случайного выбора клана больше нет.

## Реализовано
Клиент получает флаг отсутствия персонажа и открывает простой экран с восемью происхождениями.
Слева список, справа описание и правила наследования; длинный текст прокручивается колесом мыши.
Подтверждение двухэтапное: выбор → подтверждение навсегда. Есть выход из игры.
Закрытие/замена экрана не обходят серверную проверку.

До выбора записи в Players генетики нет. Способности, усиление и тренировки отвергаются.
Ожидающий игрок удерживается в точке входа, защищён от урона, не может атаковать или
взаимодействовать с блоками/предметами через обычные действия. После выбора защита снимается
самим условием сервера; постоянный invulnerable-флаг игроку не выставляется.
Профиль не создаётся от команды genetics, запросаK или энергетического тика.

Пакет содержит только Clan ID. Сервер берёт UUID из соединения, проверяет реестр и отсутствие
профиля; после этого один раз генерирует технику и пять потенциалов. Результат остаётся скрытым.
Повторный пакет, смерть, выход, смена измерения или сезона не открывают выбор повторно.
Идентичность основана на UUID; при online-mode=true смена имени не меняет UUID.
Серверы offline-mode сами задают иную модель идентичности, которую этот мод не исправляет.

## Миграция
Существующий профиль сохраняет клан, технику, пробуждение и CE. Никакого автоматического reroll.
Версия генетики3 добавляет CharacterId, CreatedSeason и OriginSource.
Старые профили помечаются legacy, новый подтверждённый выбор — chosen.

Оператор может выполнить ОДИН РАЗ для старого профиля:
```text
/jjkclan migrate ИмяИгрока fujiwara
```
Меняется только происхождение и сбрасывается именно прежняя учебная прогрессия клана.
Полная копия старого профиля сохраняется внутри BeforeOriginMigration; техника, потенциалы,
пробуждение и идентификатор персонажа сохраняются. Повторная миграция отклоняется после перезапуска.
Техника при миграции может оставаться историческим исключением новой семьи — намеренно,
чтобы не отбирать и не перебрасывать её. Миграция не назначает новую семейную технику.
Новые chosen-профили этой процедурой не меняются.

DEV остаётся отдельным операторским отладочным обходом. Он не является обычной игровой сменой
происхождения и позволяет явно назначать генетику для тестов, как было разрешено раньше.
Перед обновлением рабочего мира всё равно сохраняйте его полную копию.
