# Генетика v3

Актуальные правила мастер-промпта2.0 заменяют случайный клан самостоятельным выбором.
В первой итерации были случайные5/15/15/65%; этот бросок УДАЛЁН.
Clan стал объектом со стабильным строковым ID; старые NBT-строки совместимы.

Обычное создание доступно только selectOrigin после проверки зарегистрированного ID и отсутствия
UUID в Players. Чтение getProfile никогда не создаёт персонажа. Порядок:
выбранный клан → совместимость → семейный бросок →75% самостоятельного пула → пять потенциалов
→ идентификатор персонажа и сезон создания → сохранение. До выбора никаких секретных бросков.

**Предложено/реализовано для новых персонажей:** пять независимых категорий потенциала
(low15%, normal65%, high18%, exceptional2%). Они сохраняются один раз, не дают кланового бонуса
к текущим100CE и пока не влияют на результат энергетических тренировок — сами тренировки ещё
не реализованы. Старые normal-потенциалы не перебрасываются. Числа тестовые, не утверждённые.
Семейные вероятности и равные веса самостоятельного пула также тестовые; подробнее BALANCE.

Случайные Небесные ограничения выключены. Защитная совместимость full_physical возвращает NONE,
не разрешает CE-способности и сезонный отбор Шести глаз; CE-доступ/выход показывают0.
Полноценная альтернативная физическая прогрессия остаётся задачей отдельного этапа.

Миграцияv2→v3 добавляет CharacterId, CreatedSeason, OriginSource. Клан/техника/пробуждение,
потенциалы и неизвестные поля не перебрасываются. Неизвестный будущий формат не заменяется
пустыми данными: PersistentStore учитывает проглатывание ошибок загрузки Minecraft.
Старый NONE остаётсяNONE. Операторская одноразовая миграция описана в CLAN_SELECTION.

Профиль хранит ClanProgress отдельно от энергетического SavedData. Генетика и сезонный
реестр остаются в одном файле `jujutsurpg_genetics.dat`.
Секрет Technique отправляется обычному клиенту только как hidden до пробуждения.
