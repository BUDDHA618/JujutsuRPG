# Генетика и сезоны

**Утверждено:** одно серверное назначение клана и основной техники; отсутствие переброса при
смерти/перезаходе/пробуждении. Если клановая техника не выпала —75% на самостоятельную.
Шесть глаз — один владелец на сезон, независимо от Безграничности; неактивность не освобождает слот.

**Реализовано:** восемь самостоятельных ID из задания. Равные веса внутри пула — **предложение**,
не утверждённые55/30/12/3. Старые вероятности кланов5/15/15/65 и клановых техник20/10+20/40%
сохранены как тестовые. Эти коэффициенты пока в коде и требуют вынесения в настройки.
Боевые приёмы восьми новых ID ещё не реализованы; доступно общее усиление.

Миграция v2 сохраняет Clan, Technique, Awakened и неизвестные поля. Для прежних профилей
детерминированно добавляет пять отдельных потенциалов normal и Restriction=none.
Те же нейтральные значения пока используются для новых персонажей. Их случайное распределение,
эффект потенциала, Небесные ограничения и совместимость будущих ограничений НЕ реализованы.
Старый NONE не получает новую случайную попытку. Неизвестный ID сохраняется в NBT.
Будущая версия отклоняется, а не затирается старым кодом.

## Предложенный и реализованный сезонный протокол
OP регистрирует совместимых игроков командой enroll. Кандидаты — UUID клана Годжо,
включая игроков без Безграничности. У каждого ровно одна запись; повторная регистрация
не увеличивает шанс. Draw выбирает равновероятно среди совместимых зарегистрированных UUID,
в том числе офлайн. Повторный draw занятого слота невозможен. Регистрация после выбора закрыта.
OP определяет окно регистрации вручную: календарь и автоматический поиск участников — план.
Это управляемая администратором процедура, а не гарантия честности администратора.

Смена сезона требует текущего номера: next1 после перехода не сможет повторно завершить сезон2.
Архив содержит владельца и участников; новые активные права пусты. Сама генетика не меняется.
DEV-смена клана владельца временно лишает совместимости, но НЕ освобождает занятый слот.
Удаление файла реестра/восстановление старого бэкапа вне мода не защищены этим протоколом.

**Предложено/реализовано:** Шесть глаз уменьшают именно потери CE множителем0.1 по умолчанию,
не базовую стоимость и не выход. Коэффициент в serverconfig. Восприятие/особые приёмы — план.
