# Способности

**Реализовано:** LimitlessAbilities проверяет скрытую/пробуждённую технику, дальность,
перезарядку, цели, защиту блоков и общий CursedEnergy.tryTechnique. Усиление использует
tryMaintained с тем же окном выхода. Это две работающие реализации, но не универсальный движок.

**Целевая спецификация:** AbilityDefinition(id,kind,requirements,cost,output,cooldown,targetPolicy)
и AbilityExecution(owner,dimension,phase,startTick,remainingTicks).
Requirement проверяет происхождение, пробуждение, владение, контроль, освоенные действия.
AbilityService серверно проверяет цель/границы, затем атомарно списывает CE и фиксирует запуск.
Стоимость/урон/результат не принимаются от клиента. При прерывании уже потраченная CE не возвращается.
Поддерживаемое действие тикает с общей транзакцией; снаряд/призыв имеет ограниченный срок и владельца.
Logout/death/dimensionchange завершают действие по явной политике.

добавить требования отдельного мастерства после ProgressionService; затем реализовать Пропорцию.
