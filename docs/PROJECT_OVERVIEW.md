# JujutsuRPG: состояние и границы этапа

Дата: 25.10.2026. Minecraft 1.20.1, Forge 47.4.28, Java17, wrapper Gradle8.8.
Ветка foundation продолжает проверенный commit91e83d8; main не заменяется.

## Аудит до изменений
Работали сохранение клана/техники, скрытие до административного пробуждения, K, DEV,
бесконечная CE для OP, три атаки Безграничности, три проклятия, студенты, генерация техникума,
импорт NBT с предпросмотром и HUD. Это прототипы, не законченная RPG.
Отсутствовали сезонный реестр, самостоятельный пул75%, версии генетики,
нормальная прогрессия, испытания, движок способностей, территории, шикигами и ранги.
Энергетические поля существовали, но формула расхода делила стоимость на Efficiency,
усиление было эффектом зелья на10сек, а меню не показывало выход/контроль/потери.

GitHub подтвердил91e83d8. Содержимое отслеживаемых исходников C:/MincraftDev/JujutsuRPG
сверено с рабочей копией: отличия четырёх файлов только окончания строк.
Git status в пользовательской папке сообщил `must be run in a work tree`; конфигурация
и файлы там не изменялись. Рабочая копия имела только неотслеживаемые logs/; они сохранены.

## Результат текущего этапа
Законченный набор: аддитивная миграция генетики, независимый пул для НОВЫХ персонажей,
сезонный отбор и архив, общая формула затрат, поддерживаемое усиление, функциональные
энергетические поля в меню, автоматические NBT/логические и Forge-серверные проверки.
Старые NONE не перебрасываются. Шесть глаз не выдают Безграничность.

Документы различают: **утверждено** — правила пользователя; **реализовано** — код;
**предложено** — изменяемый баланс/дизайн; **план** — отсутствует в исполнении.
Наличие названия техники в генетическом каталоге не означает наличие её боевых приёмов.
Визуальные системы сохранены; новую стилизацию на этом этапе не делали.
