# Территории — проект, не реализовано

DomainService будет хранить ограниченный по размеру и времени серверный контекст области:
владелец, участники, центр/радиус, CE-поддержание, барьер, правила целей, время окончания.
Первый прототип должен работать без перестройки мира: область и правила, а не тысячи блоков.

Вход/выход проверяется сервером. Гарантированное попадание действует только на допустимые цели
в активной области и имеет явные контрмеры (простая территория, разрушение барьера).
Столкновение сравнивает подтверждённое мастерство и доступный выход, без случайного удаления.
Бюджет: ограничение одновременно активных областей и поиск участников с интервалом5тиков.

Выгорание техники, энергетическая перегрузка и истощение CE — отдельные состояния.
После закрытия территории сначала очищаются правила/участники, затем начинается выгорание.
Не хранить бессрочные ссылки на отключившихся игроков. Реализация ждёт движок способностей.
